# Учебная платформа — финальная версия для защиты

## Запуск

```bash
python main_admin.py
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8080
```

## Доступ

Для проверки системы используются пользователи, которые уже сохранены в базе данных `learning_platform.db`:

- администратор: `admin / admin123`
- преподаватель: `mentor / mentor123`
- студент: `student / student123`

Эти данные не показываются на главной странице сайта.

## Откуда берутся данные

Все данные сайта берутся из одной базы данных `learning_platform.db`:

- пользователи;
- роли;
- курсы;
- уроки;
- материалы;
- домашние задания и оценки;
- посещаемость;
- расписание;
- заявки;
- оплаты.

Админ-панель и сайт работают с одной и той же базой данных. Если в админке добавить курс, урок или материал, после обновления страницы эти данные отображаются на сайте.

## Материалы

Файлы материалов находятся в папке `lesson_materials/`. Они связаны с таблицей `lesson_materials` в базе данных и доступны для скачивания в разделе «Материалы».

## Роли

- Администратор видит управление пользователями, курсами, уроками, материалами, оценками, посещаемостью и админ-панель.
- Преподаватель видит свои учебные разделы: курсы, уроки, материалы, оценки, посещаемость и расписание.
- Студент видит только свои курсы, материалы, оценки, посещаемость и прогресс.


## AI-помощник Gemini

В проект добавлен AI-помощник для студентов. Он работает через endpoint `/ai/chat` и использует Google Gemini API.

Для включения настоящего Gemini нужно создать файл `.env` рядом с `main_admin.py` и добавить:

```env
GEMINI_API_KEY=ваш_ключ_gemini
```

Если ключ не указан или интернет недоступен, система автоматически использует локальные ответы, чтобы демонстрация на защите не ломалась.

Что сказать на защите:

> В учебную платформу добавлен AI-модуль интеллектуальной поддержки студентов. AI-помощник использует Gemini API для ответа на вопросы по учебным материалам, домашним заданиям и подготовке к занятиям.

## AI-модуль проверки домашних заданий и тестирования

В систему добавлены два дополнительных AI-сценария для специальности «Искусственный интеллект»:

1. **AI Проверка ДЗ** — студент или преподаватель вставляет текст домашнего задания, после чего AI анализирует ответ и возвращает:
   - оценку от 0 до 100;
   - уровень выполнения;
   - общий отзыв;
   - сильные стороны;
   - ошибки;
   - рекомендации по улучшению.

2. **AI Тест** — AI генерирует тест по выбранной теме, а система проверяет ответы студента и показывает результат в процентах.

Если `GEMINI_API_KEY` указан в `.env`, используется Gemini API. Если интернет или сертификаты недоступны, система автоматически переходит в локальный режим, чтобы демонстрация на защите не прерывалась.
